# Customer Database Cleaning & Organization

## Project Overview

This is a fictional demonstration project showing how customer
data can be cleaned, standardized, and organized using Python.

## Problems Identified

- Duplicate customer records
- Inconsistent name capitalization
- Inconsistent email formatting
- Inconsistent city names

## Work Completed

- Removed duplicate records
- Standardized customer names
- Converted emails to lowercase
- Standardized city names
- Formatted date values
- Preserved phone numbers as text

## Results

| Metric | Result |
|---|---:|
| Original records | 7 |
| Duplicate records removed | 2 |
| Final unique records | 5 |

## Deliverables

- Cleaned Excel workbook
- PDF report

- Python
- pandas
- openpyxl

- GitHub Actions
